# 应用 Logo 替换

采用用户提供的橙色图形与深蓝背景 PNG。原始文件保存在 `assets/app_icon_source.png`，与用户原图字节一致。

按用户反馈，应用左上角移除小图标，只保留 Eidory 文字。应用窗口图标与 macOS 打包图标使用同一份圆角 PNG，在不同主题下保持原色。

`scripts/build_app_icon.sh` 先调用 `tools/render_app_icon.swift`：使用 AppKit 把原图等比缩放到 1024 像素画布中间的 824 像素区域，四边留 100 像素透明空间，圆角半径 185 像素。输出 `src/eidory/ui/icons/app_icon.png` 为真正 RGBA PNG，四角与外边距透明，不重绘内部图形。随后使用 sips 和 iconutil 生成 `assets/app_icon.icns`，包含 16、32、128、256、512 点的普通及 Retina 图标（共 10 种表示，最大 1024 像素）。macOS 构建脚本已接入该步骤。Python 包和 PyInstaller 都包含 PNG 资源。

参考 Apple 的 [App 图标指南](https://developer.apple.com/cn/design/human-interface-guidelines/app-icons/) 中的圆角外形。本项目采用传统 ICNS 打包，因此在资源中落实透明轮廓。

曾使用内置 imagegen，提示词要求“保留原图形、深蓝底色，仅添加圆角裁切和透明外边距”。两次输出均为带棋盘格像素的 RGB 图像，没有透明通道，均未用于项目；最终资源由上述原生构建步骤从用户原图生成。

本次验证：工作台相关测试 18 项通过；PNG 为 1024×1024 RGBA，非透明区域边界为 (100, 100, 924, 924)，角落透明、中心不透明。日志保存在 `build/qa/rounded-logo-tests.log` 和 `build/qa/rounded-logo-build.log`。前次主题与工作台相关测试 27 项通过的日志仍保留。

桌面测试：正式安装到 `/Applications/Eidory.app` 后重新启动，通过屏幕截图确认左上角只显示 Eidory 文字、图库正常显示。打开访达中正式应用的“显示简介”，屏幕检查系统图标预览为圆角矩形，外部透明。Dock 自动化读取超时，未取得 Dock 本身的截图。安装包与正式应用均通过 `codesign --verify --deep --strict`，正式应用的 ICNS 与构建资源字节一致。

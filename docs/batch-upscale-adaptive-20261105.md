# 图片墙右键批量放大与逐张尺寸调整（0.1.4）

图片墙多选图片后，右键菜单第一层提供“AI 批量放大所选 N 张…”。右键点到已选图片时保留多选；点到未选图片时沿用图库原有逻辑，切换到该图片。单选时提供“AI 放大…”。任务窗口原来的“放大图库中所选图片…”入口继续可用。

图片墙显式处理视口的右键按下事件，并抑制系统随后生成的重复菜单事件，以兼容 Mac 原生输入。

## 每张图片单独决定倍率

| 首选倍率 | 原图长边 | 实际操作 |
| --- | --- | --- |
| 4 倍 | ≤ 1024 | 原尺寸输入，放大 4 倍 |
| 4 倍 | > 1024 且 ≤ 2048 | 原尺寸输入，改为放大 2 倍 |
| 4 倍或 2 倍 | > 2048 | 把临时输入副本缩到长边 2048，再放大 2 倍 |
| 2 倍 | ≤ 2048 | 原尺寸输入，放大 2 倍 |

输出长边上限 4096；保持原图比例，沿用偶数像素对齐规则。首选 4 倍时不会为达到 4 倍而额外缩小本来可以做 2 倍的原图。

例如，同批选择长边 800、1600 和 5000 的三张图，首选 4 倍时实际输出长边分别为 3200、3200 和 4096。最后一张的输出比原图小，适用于用户希望用放大模型修复噪点或细节的场景，界面明确显示这一点。

## 查看与审核

- 排队窗口逐张显示文件名、原图尺寸、AI 输入尺寸、实际倍率、输出尺寸和调整原因；切换首选倍率时即时更新。
- 确认后，同一选择组成一个批次，保留原顺序。任务列表显示“4× → 2×”以及缩小输入的说明，重试保留最初首选倍率和批次位置。
- 只缩小 AI 输入的临时副本，磁盘原图及完整备份保留。批次完成后继续逐张审核，用户决定替换、另存为副本或放弃。
- 图片缺失、没有有效尺寸或已有排队/运行任务仍会报告具体原因。尺寸超限本身不再是排除理由。

单张预览窗口原有的显式倍率和可撤销缩小输入按钮继续按原方式工作。自动规则作用于批量队列。

# 看板滚轮与快捷操作 · 2026-09-19

## 使用方式

- 鼠标放在看板上直接滚动即可缩放，围绕鼠标位置缩放；空格拖动仍可平移。
- 黑白显示：选图时仅处理所选图片；没有选图时处理全部图片。混合彩色和黑白时统一切为黑白，再按一次统一恢复彩色。一次批量切换可整体撤销。
- 项目节点的图片墙中选中一张或多张图片，按 Enter 收集到当前节点。重复按键不会重复收集；独立图库不执行收集，搜索目标待更新时仍遵守原有检查。
- 单键快捷键仅用于看板，文字输入和弹窗保留原有键盘操作。按钮上显示对应按键；窄窗口收进“更多”后快捷键仍可使用。

| 按键 | 操作 |
| --- | --- |
| 0 | 适应全部 |
| N | 便签 |
| J | 定位菜单 |
| G | 按节点分区／取消分区 |
| Z / Y | 撤销／重做 |
| P | 窗口置顶 |
| H | 进入／退出专注看板 |
| F | 左右翻转所选图片 |
| B | 黑白显示 |
| C | 编辑局部显示 |
| V | 局部／全图切换 |
| L | 锁定／解锁所选分区 |
| 1 / 2 / 3 | 备选／主参考／暂不采用 |
| Delete | 移出看板（原有操作） |

## 性能与验证

滚轮连续缩放合并高清加载请求；黑白批量操作合并布局保存和撤销记录，复用已有图片变体缓存。快捷键过滤仅安装在实际键盘接收控件，避免为全应用每个绘制、布局事件增加处理。屏幕测试发现快速撤销、重做会丢失选图，已修复并增加回归检查。

- 相关回归 **100 项通过**，日志 `build/qa/board-controls-regression.log`。最后修复保留选图后，重跑相关 **57 项通过**，日志 `build/qa/board-controls-final-regression.log`；两批存在重叠，不累计计数。
- 合成性能测量：200 张 768×512 图片，连续切换黑白 20 次。首次转换约 233 ms，后续缓存切换中位数约 1.56 ms；变体缓存稳定在 400 份，每次仅一次布局通知。记录 `build/qa/board-controls-performance.json`。该测量是图片处理与状态操作耗时，不代表所有项目的完整屏幕渲染延迟。
- 独立测试数据 `build/qa/simpler-data`：屏幕验证滚轮缩放、全图及单图黑白、F/Z/Y 连续操作保留选图、2 设为主参考、H 进入退出专注、输入用途说明不误触快捷键。图片墙选两张按 Enter 后节点从 13 张增至 15 张，再按 Enter 数量不变。
- 已安装 `/Applications/Eidory.app`，签名校验通过；正式应用打开原 54 张图看板正常。安装前后对比图片、节点、参考关联、用途、条目、等级和节点看板布局均一致，数据库 `quick_check` 为 `ok`。

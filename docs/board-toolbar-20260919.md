# 看板工具栏按空间自动展开

空间足够时，窗口置顶、专注看板、左右翻转、黑白显示、编辑局部显示、局部／全图切换、分区锁定均直接显示。空间不足时，只将放不下的操作收进「更多」；放大窗口后自动展开。

按实际按钮宽度计算，包含字号、语言、分区按钮文字变化和侧栏占用的空间。菜单沿用原按钮的操作、可用状态和置顶勾选状态；不会改动项目或看板布局。

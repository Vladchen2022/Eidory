# 看板操作优化 · 验证与回退

## 现在的操作

| 项目 | 调整后 |
| --- | --- |
| 看板右侧栏 | 显示看板所选图片的预览、文件信息，直接编辑等级、用途和用途说明，不再重复列出整张看板的图片。 |
| 看板操作 | 在画布选图，通过上方第二排按钮设为主参考、备选或暂不采用，支持多选；移出看板只解除关联。 |
| 项目看板入口 | 从构思或找参考进入项目根节点看板，不受此前搜索结果集状态影响；看板页不再重复显示进入看板按钮。 |
| 节点分区 | 点击「取消分区 · 自由排列」只移除分区框，保留图片位置、大小和便签；可以撤销。再次按节点分区会重新整理。 |
| 主参考标记 | 红色边框与 ★ 角标。蓝色内框表示当前选中；取消选择后红框仍在，缩小画布后边框保持屏幕粗细。 |

同一图片若属于多个节点，先在右侧明确要修改哪个节点的用途，也可明确选择当前看板内的全部用途。单张图片只属于一个节点时自动选择该节点。多图可批量设置等级、用途，用途说明需单独编辑。

移出图片后撤销会同时恢复参考等级、用途和说明。已有锁定分区可通过取消分区解除分区结构；图片自身的锁定仍保留，可在图片菜单中解锁。

## 可自行复核

- 在看板选一张图，点「★ 主参考」；观察红框，取消选择后应继续显示。
- 直接在右侧改用途、写说明；切换图片再回来，应仍保留，无需跳页。
- 点击「取消分区 · 自由排列」，拖一张图到空白处；点击撤销恢复移动，再撤销恢复分区。
- 选图后「移出看板」，再点「撤销编辑」，检查图片与等级、用途说明恢复。

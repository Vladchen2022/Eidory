# 五种主题配色

设置窗口顶部新增“主题配色”，选择后立即生效并自动保存到 `ui.theme`。启动读取该设置；不存在或无法识别的主题回退到石墨深色。界面密度单独保存，调整密度不会重置主题。

| 显示名称 | 设置值 | 外观 |
| --- | --- | --- |
| 石墨深色 | graphite | 中性深灰，默认主题 |
| 明亮浅色 | light | 浅灰与白色，蓝色操作按钮 |
| 暖纸米白 | paper | 米白与暖灰，棕色操作按钮 |
| 午夜蓝 | midnight | 深蓝灰，蓝色操作按钮 |
| 森林绿 | forest | 深灰绿，绿色操作按钮 |

## 实现范围

- 主窗口、导航、筛选条件、标签、设置、后台任务与普通弹窗使用共享主题颜色。
- 自绘的项目列表、文件夹层级、看板背景与文字、图片缺失占位、预览背景和工具图标也跟随主题。
- 已打开的控件在原位置更新配色，不重建搜索结果、项目或看板。
- 图库图片、用户选择的颜色条件、图片叠加提示本身不做颜色替换；图片上的提示保持独立的前景／背景对比。
- 看板导出使用当前画布主题，图片像素和保存的看板内容不因切换主题改变。
- 浅色主题使用专门的深色下拉箭头，避免白底浅色图标。

运行库保持 PySide6 6.9.3，不升级 Qt。本次不涉及数据库结构迁移。

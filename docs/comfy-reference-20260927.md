# 本机 ComfyUI 生成参考 · 使用与验收

## 使用方式

1. 启动本机 ComfyUI，在 Eidory 选择项目中的具体节点，进入「找参考 → 生成参考」。
2. 检查自动带入的主题、世界观和当前节点描述，按需要修改，点击「生成 1 张」。
3. 结果先留在生成面板。可放大、滚轮缩放、再生成，或丢弃后撤销。
4. 点击「采用并保存到『节点名』」。第一次选择永久保存的图库文件夹；同一项目以后沿用。采用同时保存图片并加入原节点，切换页面不会改变归属。
5. 返回看板，用原有操作整理、设为主参考和填写用途。

本机已绑定 `Qwen21-reference.api.json`，地址为 `http://127.0.0.1:8188`。导入后工作流存入应用设置，不依赖该 JSON 文件继续存在。原 ComfyUI 工作流文件和浏览器里的编辑不被修改。

「生成设置」可重新绑定 ComfyUI API 格式 JSON、检查连接、调整尺寸和保存位置。保留工作流中的模型、步数、采样器和 CFG，每次使用新种子。首版支持单个 KSampler、单图片输出、直接文字编码和空白画布的文生图流程；复杂分支、图生图、多输出工作流会明确拒绝。

## 临时与永久保存

- 未采用的候选存于 `~/Library/Application Support/Eidory/generated-references/candidates/`，关闭或重启 Eidory 不会清空，不进入普通图库和索引队列。
- 丢弃后移入同目录下的 `discarded/`，可撤销；当前版本不自动永久清理。
- 采用默认存于 `~/Pictures/Eidory Imports/AI生成/<项目名>/`，也可选现有图库文件夹。图片旁的 JSON 保存提示词、种子和完整生成工作流，图库备注也标记 AI 来源。
- 与 ComfyUI 的交换输出使用其临时预览目录；Eidory 收到后保存自己的持久副本，不向 ComfyUI 原来的正式输出目录写入测试图。
- 只取消 Eidory 自己的任务，使用本机服务提供的 `/api/jobs/{id}/cancel`。没有该接口的服务会报错，不退回全局中断。关闭面板或退出 Eidory不会取消服务中已经接受的任务。
- 断线后核对同一任务；不自动重复提交。服务重启后若已清空历史和临时输出，未取回的图片可能无法恢复，界面会说明。

# 节点内容形式与批量补全

## 行为

合并两个重复入口，只保留“批量补全项目节点”，旁边说明“跳过已锁定和待采纳节点”。单节点与批量补全使用同一份节点形式设置。

“整体说明”生成连贯短段落和独立的找图语句，适合设定、氛围、构图以及身份、时间、动作、工作状态等整体决定。“参考条目”沿用可勾选的搜索目标与细节描述。AI 建议仍先预览、编辑、采纳，不直接覆盖原文。

短文使用独立 JSON schema（note/search_query），不把物件数组压成散文。检验字段、长度、列表格式、重复原文与搜索范围，失败时最多重试一次；模型会得到上次输出和具体校验原因。再次失败保留原文并提示错误。不能由格式校验保证创意质量。

模板占位搜索文字不会成为用户已确定内容。中文模式要求搜索语句包含中文；新增短文保持为一个段落，原文格式保留。

## 六种模板

| 模板 | 默认整体说明 | 默认参考条目 |
| --- | --- | --- |
| 故事性插画 | 世界观、时间、事件、氛围、构图 | 地点、物件、人物 |
| 室内人文环境 | 世界观、空间功能、动线与视角、材质表面、灯光与色彩、构图焦点 | 建筑与布局、陈设与道具、生活痕迹 |
| 室外人文环境 | 世界观、交通与动线、天气与光照、构图焦点 | 地点类型、地形与尺度、建筑群轮廓、公共设施、人群活动痕迹 |
| 自然环境 | 世界观、岩石土壤材质、时间与光照、路径与危险、构图焦点 | 地貌结构、植被生态、水体与气候、生命迹象、尺度参照 |
| 角色设计 | 世界观、身份、身体结构、头面部 | 穿戴、物件 |
| 物件设计 | 世界观、使用者与用途、整体轮廓、材质工艺、工作状态、展示尺度 | 结构拆解、交互细节、使用痕迹 |

根节点默认整体说明。新模板节点保存明确的形式；旧项目按节点标题匹配。自定义子节点优先识别自身名称，再继承最近的已知父节点；无法判断时默认短文。比如“物件/光照”仍是短文，“人物/主角”是条目。

用户可以通过“内容形式”修改默认选择。锁定、生成中或待采纳时不能切换。条目转短文保留完整文字，并快照原条目 ID、勾选状态与形式，可用恢复按钮撤回；转条目不会凭空自动拆文，用户可选择“将原文整理为条目”。旧条目不自动改写。

## 数据与回退

`creative_node_workflow` 和 `creative_node_versions` 添加 `content_format`，默认空值，迁移不转换已有内容。采纳条目、切换形式及恢复均保留相应状态。搜索继续使用原有图库和筛选引擎。

代码回退点为 `checkpoint/before-node-content-formats-20260913`（4774b1c），开发分支 `codex/node-content-formats`。回退旧程序仍可读取兼容的说明文本。

本地旧版程序保存在 `build/rollback/Eidory-before-node-content-formats.app`，升级前数据库快照保存在 `build/rollback/eidory-before-node-content-formats.sqlite3`。需要回退时先退出 Eidory，用旧版程序替换 `/Applications/Eidory.app` 即可。数据库快照仅用于数据恢复；直接覆盖现库会丢掉备份之后的编辑，不应随程序回退自动覆盖。

## 验证

六种模板的每个节点均覆盖生成路径、待采纳展示与原文保留测试；另外覆盖单节点短文的搜索语句隔离、形式切换/恢复/重启、锁定与待采纳保护、自定义节点、旧条目和旧库迁移。

回归日志和屏幕测试副本记录在 `build/qa/node-formats/`（不纳入 Git）。屏幕测试使用独立数据库 `/tmp/eidory-node-formats-qa/eidory.sqlite3`，不向用户真实项目写入测试建议。

339 项相关测试通过：节点形式 14、参考条目 13、创作工作区 13、节点补全 19、灵感 53、主窗口交互 195、筛选流程 32。最终日志为 `tests-workflow-final.log`、`tests-context-verified.log`、`tests-inspiration.log` 和 `tests-filter.log`。

原生软件屏幕测试覆盖六种模板的短文/条目入口与锁定状态，并调用本机 LM Studio 模型验证以下案例：

- 角色设计批量补全：仅处理未锁定的“身份”“穿戴”，分别产生短文和 5 个穿戴条目；其余已锁定节点保持不变。
- 穿戴条目：取消 3 项、采纳 2 项，转为短文再恢复后，5 个条目及各自勾选状态完全恢复。按勾选项搜索形成两个“任一满足”条件；屏幕拖动严格程度从 50 到 85，结果从 10751 张减少到 250 张。
- 物件结构：手摇净水器生成接口、流速计、排污阀、悬挂支架和维护扳手 5 个条目，原有“禁止电力装置”说明保留。这里验证的是生成、预览及原文保护流程，不是工程可制造性。
- 世界观最终复测：原有低技术时代、工匠协作和禁止魔法的文字完整保留，新增内容合并成一个段落；无模板提示混入，找图语句为中文。采纳后点击找参考，在图片墙得到一个语义条件与 10460 张结果（匹配强度 50）。
- 重启最终打包程序后，“穿戴”的 5 个条目与仅前 2 项勾选的状态仍正确显示。

首轮短文不符合格式时，界面保留原文并提示失败。屏幕复测还发现模板文字混入搜索约束与中文查询返回英文，均已修复并加入回归测试。

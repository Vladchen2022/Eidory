# 创作交互改版 · 验收与回退

实施分支：`codex/creative-ui-20260916`。升级前基线：`452f4fb`。

本轮重排操作入口与内容呈现，沿用现有项目、节点、搜索、参考等级、看板、方案和导出功能；没有新增数据库表。

## 可以直接体验的变化

| 位置 | 新的操作方式 |
| --- | --- |
| 构思入口 | 填一句主题、选择类型即可开始；补充约束按需展开，也能继续已有项目或先浏览图库。 |
| 项目全貌 | 用内容卡片显示世界观、人物、地点等设定、状态与参考缩略图，可直接进入编辑或找图。 |
| 具体构思 | 原有设定单独保留，独立想法各占一张卡片。AI 建议逐条采用、编辑或略过。整体说明类内容继续使用短文。 |
| 构思到找图 | 点击“找参考”或“找它的参考”，右侧同时显示本次目标、收集目的地和参考托盘。 |
| 搜索目标 | 勾选决定搜索哪些内容；展开“调整找图用语”独立修改搜索表达，不改写构思。输入即保存，更新结果前禁止收集旧结果。 |
| 收集与整理 | 图片直接收集到当前内容；托盘可展开、移出和撤销。等级改为备选、主参考、暂不采用三个直接选项。 |
| 看板与保存 | 三个主要阶段为构思、找参考、看板。项目全貌提供整理看板、保存与恢复方案、导出参考包入口。 |
| 高级功能 | 左右保留/排除筛选继续保留；无条件时可收起空框，有条件时始终显示。批量补全、格式切换、恢复、文案和灵感探索仍可使用。 |

“采用想法”“勾选搜索目标”“收集图片”分别执行各自的操作，不再共用一组含义模糊的勾选框。

## 测试中发现并修复的问题

1. 切换创作内容时可能继续显示另一节点的已收集图片或看板，现随当前内容重新显示。
2. 改了目标但仍显示旧搜索结果时，可能误收集；现明确标记旧结果并暂停收集，搜索进行中也禁止收集旧结果。
3. 找图用语依赖输入框失焦才保存；现输入即保存，不会在直接点击搜索时遗漏修改。
4. 模板的填写提示可能直接参与搜索；现空内容先要求指定目标，新填写的原文可以成为核心搜索目标。
5. 从入口继续已有项目时，顶部可能仍显示独立图库；现同步项目选择。新建项目清空上一份输入，返回项目全貌使用项目整体上下文。
6. 简短标签和控件被纵向拉大；现多余高度留在编辑区底部，卡片按内容排列。
7. 移出图片后项目计数不及时刷新；现同步更新并支持撤销。
8. 项目总托盘误用根节点等级，导致子节点主参考显示成备选；现按实际所属内容显示。多处使用的图片明确标注，编辑时选择对应内容。
9. 参考等级的辅助功能操作可能只改变外观；现使用互斥选择并同步实际数据。
10. 延迟进入看板可能覆盖后续导航；改为立即完成页面切换。同时保留节点树的键盘焦点，连续方向键不会被看板抢走。两个场景均已增加回归测试，连续节点切换和返回构思也已在屏幕复核。

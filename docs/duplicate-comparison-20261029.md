# 重复图片并列对比

检测结果窗口新增“并列对比 / 处理重复图片”按钮，也可双击一组或组内图片进入。打开后从选中组开始浏览；每张图片与自己的文件名、所属文件夹、尺寸、文件大小、修改时间和完整路径放在同一列。信息按行对齐，长路径换行并可复制。界面每次只显示两张。完全重复组包含多份文件时，左侧固定基准图，右侧通过“本组上一份 / 下一份”切换。

预览沿用现有的异步解码、缩放和拖动能力；“适应窗口”重置本组所有预览。切组后，旧解码结果不会覆盖当前图片。源图不可读时尝试缓存缩略图，并标注缓存来源；信息和操作仍可使用。

对比页将预览缩放下限设为 0.1%，使 12,285 像素等超大横图和竖图也能完整适应窗口；继续滚轮放大时保持平滑步进。其他预览窗口保留原有默认缩放下限。

## 操作

| 操作 | 快捷键 / 入口 | 结果 |
| --- | --- | --- |
| 选择操作对象 | 点击图片、图片信息或“选择此图” | 高亮这一列，显示当前对象 |
| 删除源文件 | Delete / Backspace，或该图片下方按钮 | 复用持久化回收备份，再移到废纸篓并移除索引 |
| 只从图库移除 | macOS Command+Delete / Command+Backspace，或该图片下方按钮 | 保留硬盘源文件，只移除索引 |
| 切组 | 左右方向键，或“上一组 / 下一组” | 切换候选组 |
| 切换本组副本 | 上下方向键，或“本组上一份 / 下一份” | 保持左侧基准图，切换右侧副本 |
| 撤销 | Command+Z，或“撤销上次删除 / 移除” | 复用已有恢复机制，同时恢复本次检测中受影响的组 |

Windows / Linux 使用 Ctrl 替代 Command。快捷键只作用于当前明确选中的图片。切组、操作完成或操作失败后均清空选择，按住删除键不会连续删除。每张图片下方的按钮始终处理本列图片，与图片墙的选中项无关。

一个组剩余不足两张时退出重复候选，继续显示后续组；最后一组处理完成后显示完成状态，仍可撤销。近似检测已改为两图直接核验，不再使用相似关系的传递合并；另检查宽高比、局部结构与颜色差异。完全重复仍按 SHA-256 分组，无数据库结构变更。近似检测偏保守，较大裁切或明显改色可能不再命中。

浏览队列按本次检测顺序固定。窗口同时显示待处理位置、原检测编号和已解决数量。删除当前组后只进入原顺序中的下一有效组；共享同一图片的其他近似对不再影响定位。撤销恢复原顺序并保留当前可见组。详见 [导航修复](duplicate-navigation-20261029.md)。

# 重复图片大组与展示修复

旧版使用并查集合并感知哈希距离不超过 8 的图片，导致相似关系被错误传递。真实图库中复现了一个包含 2799 张图片的近似组，其中港口与山谷图片的直接哈希距离为 18，本不满足近似门槛。对比弹窗又为组内每张图片创建预览，放大了这个问题。

## 最终行为

- 近似结果只包含两张直接匹配的图片，禁止通过中间图片串成大组。
- 在哈希候选上增加宽高比、32×32 RGB 颜色误差和局部结构核验。宽高比差异不超过约 5%，结构得分至少 0.90，归一化 RGB 误差不超过 0.12。这些是筛选阈值，并非重复概率；较大裁切、重调色可能漏检。
- 每个完全相同的 SHA-256 文件族只用一份代表参与近似匹配，避免同一个近似关系被每份完全相同副本重复放大。
- 完全重复仍按文件 SHA-256 分组。对比页始终只创建两列和两个预览；多份完全相同文件用固定基准图与可切换副本逐一比较。
- 左右方向键切组，上下方向键切换本组副本。切换时清空操作对象，隐藏副本不能被删除。删除基准图后改用剩余图片继续对比，撤销恢复成员。
- 旧版包含多张图片的近似连通组不能直接进入删除决策，提示重新检测。
- 文件夹层级批量读取，避免每张图片重复读取整棵文件夹树。

## 验证

- 43 项重复检测、对比和原有结果窗口相关测试通过。
- 104 项相关回归通过，覆盖真实临时文件的移除 / 删除 / 撤销、误判链条、颜色与结构碰撞、2799 张输入、只加载两个预览、隐藏对象隔离、切换、基准图移除及完整文件夹层级。
- 真实图库只读重跑为 447 对近似候选，每个近似结果严格为两张，未再生成 2799 张近似大组。截图中的港口图与山谷图不在同一候选对中。该结果不是对所有候选正确性的人工标注评测。
- 修复版已签名校验并安装到 `/Applications/Eidory.app`。安装版重跑真实图库显示 448 组（1 组完全重复、447 对近似候选），已原生检查完全重复与近似结果均只显示两张，左右键可切组，完整文件夹信息正常显示。应用留在真实近似候选对比页。
- 原始复现、只读审计、截图、回归和构建日志位于 `build/qa/duplicate-repair/`。
- 此次修复前的应用与数据库一致性备份位于 `build/rollback/duplicate-group-repair-20261029/`。备份数据库有 28,517 条图片记录；核对图片、标签、项目等内容未变，数据库 `quick_check` 为 `ok`。扫描时间等运行时间戳单独处理。

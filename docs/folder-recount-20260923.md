# 文件夹数量与删除同步 · 2026-09-23

## 实际核对

“AI 场景”有 6,250 条图片记录，对应文件全部存在，没有发现缺失文件仍占用计数。
该软件文件夹聚合了三个磁盘位置，不仅是同名保存目录：

| 位置（相对于用户 Pictures 目录） | 文件数 |
| --- | ---: |
| AI生成图库 | 223 |
| Eidory Imports/AI生成图库 | 3,759 |
| Eidory Imports/AI 场景 | 2,268 |
| 合计 | 6,250 |

此前具体删除了哪些图片，现有持久记录不足以确认；不能据此认定用户看到的历史变化有误。
这里核对的是文件记录数量，不是图像内容去重数量。

## 调整

- 图片墙删除、撤销后立即失效数量缓存，使侧栏、详情与图片墙保持一致。
- 自动扫描发现删除时同步刷新当前结果，避免继续显示已被删除的旧图片。
- 文件在目录枚举与读取属性之间被删除时跳过该文件，继续完成扫描。
- 子目录读取失败时中止扫描，不以不完整结果清理该目录的记录。
- 文件夹右键增加唯一的“刷新文件夹数量”入口，作为手动核对补救。包含子文件夹，同一图片记录只计一次；后台检查文件状态，不解码图片、不生成索引、不导入未收录文件。
- 手动核对只标记缺失和恢复，不删除记录及其标签、项目关联。目录整体不可用或权限不足时保留原状态，明确报告未核对数量。

软件运行且文件监听开启时，Finder 删除事件合并约 1.5 秒后启动后台扫描；最终同步时间还取决于目录大小和磁盘速度，并非零延迟。

# 入口精简 · 2026-09-19

本轮保持构思、找参考、看板三阶段和现有功能，清理通往同一位置的重复入口。

| 操作 | 保留的位置 | 移除的重复位置 |
| --- | --- | --- |
| 选择项目／参考集、新建项目、返回独立图库 | 顶部项目选择器；列表保留右键管理和排序 | 左侧项目列表、首页最近项目按钮、原项目下拉框 |
| 项目全貌 | 子节点工作时，阶段栏右侧的“项目全貌”；项目根节点使用“构思” | 节点编辑器的“‹ 项目全貌” |
| 为整个当前节点找参考 | 顶部“找参考” | 节点编辑器的“找参考 →”、搜索区“返回构思” |
| 进入看板 | 顶部“看板” | 项目全貌底部“整理项目看板”、参考侧栏“项目看板 →” |
| 主题与补充设定 | 项目工具 | 项目全貌及节点“更多”中的同名入口 |
| 方案版本、导出创作参考包 | 项目工具 | 项目全貌底部及用途侧栏的同功能按钮 |
| 批量补全、项目文案、探索灵感方向 | 项目工具 | 节点“更多”和左侧“探索灵感方向” |
| 功能准备检查 | 设置 | 项目工具菜单 |
| 当前节点的内容形式与恢复 | 节点标题旁的“内容选项” | 原“更多”菜单中的一层中转 |

“项目总览”改名“项目检查”，与用于浏览创作内容的“项目全貌”区分。单条想法的“找它的参考”保留，因为它只搜索该条想法，与搜索整个节点不同；快捷键保留。

找图页面显示当前构思的简短摘要，单行显示，宽度不足自动省略，悬停可读完整原文；不改写构思，也不把摘要另作为搜索条件。

## 检查方式

- 顶部打开项目选择器，选择项目；在列表使用方向键浏览，Enter 打开，Esc 取消。浏览和取消不应加载另一个项目。
- 新建测试项目，编辑一个物件节点；使用顶部“找参考”，确认原构思摘要、收集目的地和结果一致。
- 选图后 Enter 收集，顶部进入看板；再回到构思，仍应保留当前节点。
- 项目工具内检查主题、方案、导出、批量补全、文案和灵感入口；设置内仍可进入功能准备检查。
- 选择独立图库，主区应回到图片墙，看板不可用。
- 缩窄窗口，确认项目选择器能使用，看板常用工具仍按宽度自动收纳。

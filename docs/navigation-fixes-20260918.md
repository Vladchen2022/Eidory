## 已修复的原因与行为

| 入口 | 原问题 | 修复后的行为 |
| --- | --- | --- |
| 标签右键 → 搜索带有此标签的图片 | 只改变标签管理列表的选中项，新筛选器不读取这个旧状态 | 在全部图库范围建立明确的标签条件，应用并进入图片墙；替换旧查询、排除条件和固定结果范围 |
| 项目下拉框 → 独立图库 | 清空项目 ID 后仍留在旧看板；看板按钮仍可选中 | 保存尚未落盘的看板位置和用途，退出项目，清除项目搜索上下文，回到图库图片墙，看板按钮禁用 |
| 看板 → 文件夹、未标签、AI 未标记分类 | 在隐藏的图片墙更新结果，或继续使用之前收集图片的固定范围 | 切回可见图片墙，按所选范围执行筛选，现有可见筛选条件保留 |
| 独立图库 → 项目工具 | 项目总览、版本、导出看起来可用，点击却提前返回 | 没有创作项目时禁用这三项，导入与功能准备检查继续可用 |
| 临时参考集 / 搜索结果集 | 没有创作项目时，顶部依旧显示独立图库，实际却在参考集内 | 顶部显示正在使用的参考集；再选择独立图库可完整退出。临时参考集保留看板，搜索结果集仍使用图片墙 |
| 搜索结果集 → 创作项目看板 | 旧结果集标识可能阻止再次进入项目看板 | 显式进入创作项目时清除旧结果集标识 |

标签右键搜索继续遵守用户设置的“停用搜索”文件夹限制。正常选择标签仍用于管理标签，只有明确点击搜索才开始筛选。

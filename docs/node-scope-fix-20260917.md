# 人物子节点的 AI 生成范围修复

问题：在「人物 / 领主」内完善方案时，AI 曾把同级的长老、奴隶一起生成，并保存到领主节点。

## 修正后的行为

- 「人物」仍可规划多个人物；「人物 / 领主」只完善领主的一条完整角色方案。「奴隶」这类群体节点返回该群体的整体方案。
- 按钮明确显示「完善“领主”方案」等当前目标。人物服装、配饰、动作放在角色细节中。
- 父节点用于继承人物设计职责，项目主题和其他节点用于约束世界观，不再视为当前子节点的生成清单。
- 单节点、细节补充、原文整理及批量补全使用同一范围约束。批量结果按请求的节点 ID 分别保存，锁定和已有待采纳建议的节点继续跳过。
- 具体角色的结构化输出必须声明当前节点，且只有一条方案。检查发生在去重、截断之前；拒绝错误归属、多行角色、同级角色冒入名称等情况。完善角色还要求名称包含当前角色，避免只返回一件衣物。
- 不合格输出自动纠正一次，仍失败则报错，保留原有内容。建议仍需用户采纳。

这些校验可保证上述结构和保存范围；不能保证模型所有自然语言细节都始终正确，内容仍需审阅。

# 预览内的本机 AI 生图与遮罩编辑

预览底部并列提供「AI 生图」「AI 编辑」「AI 放大」。生图与编辑使用本机 ComfyUI 的 Qwen Image 2.1 官方 Turbo 8 步；现有项目节点生图和 SeedVR2 放大入口保留。

## 使用

- AI 生图：输入描述，设置宽高，生成后审核；「保存到图库」选择永久文件夹，软件自动索引新图片。无需创建项目或节点。
- AI 编辑：用画笔涂选修改区域，橡皮擦修正；支持撤销、重做、清空、遮罩显示和向内羽化。滚轮缩放，按住空格拖动。输入修改要求后开始编辑。
- 完成后切换到原图／结果滑动对比，选择「替换原图」「另存副本到图库」或「放弃结果」。放弃可撤销；替换可恢复原文件。
- 返回预览与 Esc 都保留任务、候选和草稿。状态栏的「AI 生图 / 编辑」显示待审核数量，可再次进入。
- 历史下拉框保留每次任务；「当前草稿 / 新任务」可返回当前图片重新涂选。可以继续生成新候选，未决定的旧候选保留在历史中。

## 数据与任务

候选沿用 `generated_reference_jobs`，使用 `origin=preview` 与 `project_id=0` 区分，实际项目不会新增假节点。原始输入备份、遮罩、提示词、种子、工作流、候选与草稿保存在工作区 `generated-references` 下，随现有工作区迁移包迁移。

ComfyUI 使用已有本机地址设置，默认 `http://127.0.0.1:8188`。输入通过本机 API 上传；不调用外部图像服务。官方模型、CLIP、VAE 与采样调度对应本机 ComfyUI 启动器的 `Qwen21_OfficialTurbo[_Masked_Edit].json`。遮罩同时作为图像参考送入模型，解码后在本地以原始尺寸向内羽化合成，未涂选像素不接受模型结果。PNG 副本保留该像素约束；替换 JPEG 时仍会有 JPEG 重新编码带来的损耗。

所有 Eidory 生图、编辑和放大任务共用互斥约束。网络中断核对原任务，不自动重复提交；取消只使用指定任务的取消接口，不中断启动器或浏览器里的其他任务。离线停止等待后，可从历史继续核对。关闭窗口不丢结果；关闭整个应用后重新启动会恢复任务核对。

替换沿用原子的源文件替换和启动恢复机制，原图先做完整字节备份；如果原图在外部发生改变，则拒绝覆盖。手动标签、收藏、备注和项目引用保留。生成式编辑可能改变内容，替换后旧向量、颜色特征和机器识图结果标为待更新；恢复原图同时恢复替换前的机器索引快照。另存副本使用新的图片 ID 和待建立索引状态。

## 范围

遮罩编辑支持单帧 JPEG、PNG、WebP，最多 6400 万像素；EXIF 方向统一到显示方向。保留透明通道。生图尺寸为 256–2048 之间的 32 倍数。局部修改效果仍取决于模型和提示词，应在对比后决定是否采用。软件不会自动采用结果。

修改前应用、源码和数据库备份位置记录于 `build/qa/preview-ai-tools-20261108/backup-path.txt`。

## 已实现的 10 项

| 项目 | 实现结果 |
| --- | --- |
| 1. 外部文件暂时缺失 | 保留图片 ID、项目关系和标注；缺失图片不计入可用数量。文件或整个目录返回后，自动扫描恢复。监听父目录，并核对监听重建期间返回的目录。 |
| 2. 删除撤销 | 同时恢复人工标签、语义记录、AI 标签、项目参考、等级、用途与用途说明。原路径被其他文件占用时保留撤销备份，禁止覆盖。 |
| 3. 预览与选择同步 | 预览窗口绑定打开时的项目、节点和页面；旧预览不能更改新页面选择。操作只使用当前可见页面的真实选择。 |
| 4. 撤销范围 | 每个项目维护各自的撤销/重做历史。离开原节点后的看板撤销写回原节点，不阻塞当前项目的历史。恢复数据库后清空旧历史。 |
| 5. 数据库恢复 | 在私有副本上完成完整性检查、字段检查、迁移和关联检查，然后切换；切换初始化失败时恢复自动备份。旧预览和旧项目上下文不带入新数据库。 |
| 6. 图片墙解码 | 两条解码线程、小批量提交、有限待办队列；切换结果、滚动远离、隐藏页面时取消过期请求，并忽略迟到结果。 |
| 7. 看板内存 | 源图、显示图、缩略图、黑白/翻转缓存一起计入预算。每张图片只留当前变换缓存，限制高清解码尺寸，降级不改变布局。 |
| 8. ComfyUI 断线 | 断线后递增重连间隔，释放索引暂停；可停止本地等待，再核对同一任务 ID，不自动重复提交生成。生图和放大共用规则。 |
| 9. AI 请求取消 | 模型发现与生成请求放在可终止的独立网络进程；取消和退出停止本地网络等待、清理子进程，防止迟到写入。中断的 AI 标签分析回到待处理状态。 |
| 10. 项目包导入 | 先复制与校验素材，再开启短数据库事务。导入进度窗口不阻止编辑现有项目；失败清理本次私有素材。 |

取消本地 AI 等待不等于确认服务端停止推理；界面明确区分这两个状态。

## 屏幕验收中补修

1. 文件返回后，侧栏统计恢复，但图片墙仍保留缺失时的结果。扫描现在明确报告恢复数量；删除、返回、新增和变化都会刷新当前结果。
2. 恢复数据库后，已关闭的生成参考窗口仍持有旧任务选择，后台刷新报“生成记录不存在”。恢复前释放旧窗口，选中任务已不存在时清空选择；恢复结束立即更新生成入口状态。

初次测试还发现旧构建产物中的主窗口模块与源码不一致。使用干净构建并核对全部打包模块后复测；最终包不含该旧模块。测试通过表示上述具体场景通过，未测出全面的速度提升比例，也不能保证未来所有外部服务和文件变化均无故障。

# SeedVR2 7B 单图放大

## 使用

双击图库图片打开预览，点击唯一入口「AI 放大」。看板中通过图片属性的「查看大图」进入同一个预览。选择 2 倍、4 倍或指定长边后开始；沿用已有本机 ComfyUI 地址、已安装的 SeedVR2 7B FP16 和配套 VAE。无需另填提示词或重复配置工作流。

输出长边最多 4096 像素，倍数最多 8，尺寸按偶数像素对齐。超限时说明原因并禁用开始。支持图库现有的单帧 JPG、PNG、WebP；动画及视频不做静态替换。

结果和原图在同一画布中对比：拖动中线、滚轮缩放、拖动画面移动；「结果 100%」按输出像素展示，原图使用相同画面尺度。预览窗口的黑白、翻转、饱和度不写入 AI 输入。

「替换原图」保持路径、格式与图片 ID，保留用户标签、原有 AI 标签和语义向量、备注、收藏、项目/节点关联、参考等级、用途与看板布局。尺寸、文件大小、修改时间、缩略图、文件校验信息随新图片更新；不会自动重做语义识别。JPG 高质量编码，PNG 保留透明通道、内嵌文字；保留适用的 EXIF、ICC 信息，纠正照片方向。

替换前保存原文件，窗口内可「恢复原图」，重启后仍可恢复。放大期间若原文件在外部修改、移动或移出图库，则拒绝覆盖。文件替换和数据库同步有持久化记录，启动时处理意外中断。外部普通文件修改仍按原规则使 AI 信息失效；专用替换不会触发这个清除过程。

「丢弃结果」是可撤销丢弃，原图完全不动，结果不进入正式图库；同一按钮可撤销。候选、输入副本和原图备份保存在应用数据目录 `image-upscale/`，不参与普通图库计数。关闭放大窗口不会取消后台任务；退出应用后，已提交的 ComfyUI 任务继续，下次打开核对同一个任务，避免重复提交。取消仅针对本应用的任务，不打断浏览器或启动器的其他任务。

## 人工验收清单

- [ ] 从图片墙双击 JPG，打开「AI 放大」，2 倍运行后拖动对比线、滚轮缩放并移动画面。
- [ ] 替换结果后，检查原路径、JPG 格式、标签、收藏、备注、AI 标签、语义状态和节点关联，图库数量不增加。
- [ ] 关闭并重开应用，从同一图片进入放大窗口，恢复原图；确认原文件内容和尺寸恢复。
- [ ] PNG 使用 4 倍实际出图，丢弃后原图不变，撤销丢弃后结果重新可用。
- [ ] 透明 PNG 使用指定长边，确认输出尺寸和透明通道；在看板打开并替换，位置与布局不变。
- [ ] 按 Escape 关闭窗口后重新打开；生成时关闭窗口再重开，不重复提交。
- [ ] 超过 4096 像素的倍率不可提交；模型/服务不可用时说明失败原因，原图不变。
- [ ] 替换前在外部修改原图，确认拒绝覆盖；替换后重新扫描、重启，原有信息仍在。

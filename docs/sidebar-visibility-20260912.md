# 侧栏消失修复

日期：2026-09-12。运行库保持 PySide6 6.9.3。

## 已确认的复发路径

- 启动直接读取 `ui.root_splitter_sizes` 的零宽度，导致上次折叠状态继续隐藏侧栏。
- 退出时保存实际分隔布局。专注模式的临时 `[0, 中央宽度, 0]` 也会被当成下次启动布局。
- 分隔条允许拖到折叠状态，并把小于 48 的宽度解释为隐藏。
- Tab 注册为全局窗口快捷键，正常切换焦点时也可能进入专注模式。
- 顶部恢复入口只有“导航”二字，实际显示／隐藏动作仅写在悬停提示和无障碍名称中。

这些是代码中确认的路径，不能仅凭用户截图判定此次究竟由哪一次按键或拖动触发。

## 修复后的规则

- 每次启动展开左右侧栏，兼容旧的零宽度、小宽度配置。
- 收起仅作用于本次会话，由显式状态控制；尺寸变化不改变显示意图。
- 分隔条禁止折叠；可见侧栏保留最小可用宽度。
- 正常 Tab 导航不隐藏界面。专注快捷键改为 Qt 的 Ctrl+Shift+F（macOS 显示为 ⌘⇧F），看板“更多”中同步显示。
- 顶部按钮明确显示“收起左侧栏／显示左侧栏”和对应右侧动作；专注时增加“退出专注”。
- 设置中提供“恢复默认布局”，只恢复两侧栏，不修改项目、筛选、选图或看板内容。
- 图片墙延迟重排完成后完整重绘，避免侧栏切换后残留旧布局。屏幕测试发现这个问题；新增绘制测试在模拟旧行为时失败（旧绘制宽度 680，实际可用宽度 400），修复后通过。

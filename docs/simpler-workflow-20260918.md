# 简洁流程优化 · 验收与回退

基线 `046273d`；实施分支 `codex/simpler-workflow-20260918`。这一轮把操作集中在现有流程中，避免为每个能力增加独立页面。

## 十项变化与验收

| 项目 | 现在的操作 | 可以怎样检查 |
|---|---|---|
| 1. 自动更新搜索 | 修改条件、勾选目标或编辑找图用语后，短暂停顿即更新；出错时才显示重试按钮。 | 改一个目标，确认图片与数量更新，构思原文不变。 |
| 2. 图片偏好反馈 | 搜索结果右键“更像这张 / 减少这类”，只调整本次结果排序。 | 操作后用撤销或“恢复原排序”返回；图片不会被删除。 |
| 3. AI 等待与取消 | 状态栏显示耗时、批量进度、取消；失败后可重试。 | 取消一次节点补全，再发起新请求；旧响应不会写入，批量已完成的建议保留。 |
| 4. 常用编辑撤销 | 构思条目、采纳建议、参考收集/移除/评级、用途、搜索目标、看板布局接入同一操作历史。 | 连续评级、移除，然后按两次 Cmd+Z；分别恢复图片和等级。文本框内仍撤销文字。 |
| 5. 后台重建缩略图 | 重建在后台执行，状态栏显示进度并可取消。 | 选择多张图片，在设置的图库维护中重建；返回工作台后仍可操作。 |
| 6. 窄窗口收纳 | 空间不足时把排序和预设收进“显示选项”，侧栏保留。 | 缩窄窗口，检查排序仍可选；恢复宽窗口后回到工具栏。 |
| 7. 空结果恢复 | “没有结果？”列出可移除条件及预计恢复数量，点击直接更新。 | 添加一个不存在的关键词，再从恢复菜单移除它。 |
| 8. 看板定位 | 12 张以上出现小导航图；“定位”菜单支持按节点跳转、突出主参考。 | 放大后点击导航图、定位节点；图片位置和分区不会改变。 |
| 9. 双图对比 | 两侧可以同步缩放、移动，并直接评级；多张候选通过下拉切换。 | 看板选两张图右键对比，在对比中评级，返回后检查标记。 |
| 10. 图像内存控制 | 图片墙和看板按使用状态共享缓存预算；看板先载小图，放大时补清晰度。 | 大看板放大、切页、返回，确认图片清晰度恢复、布局与编辑不变。 |

撤销历史最多保留本次运行的 40 步。不同类型的物理文件操作仍保留原有恢复机制；程序重启后的整套方案恢复仍使用“方案版本”。

测试项目“简洁流程验收｜雨夜机器人维修站，两位工程师在工作台前修复机器人。”保存在独立数据副本 `build/qa/simpler-data`，没有混入正式项目。

原生屏幕测试完成：

- 编辑找图用语后自动更新，勾选搜索目标、收集 13 张参考并进入看板。
- 图片偏好调整、恢复原排序，以及修复后的图片墙 Cmd+Z 撤销。
- 看板评级、移除、按顺序撤销/重做，节点分区与自由排列切换。
- 双图同步缩放与移动、直接评级，返回看板后红色主参考标记一致。
- 看板放大、导航图定位；修复了导航图随画布滚动漂移的问题。
- 无匹配关键词产生 0 结果，从恢复菜单移除后回到图片墙。
- 500 张缩略图后台重建，成功 500、失败 0；取消与部分完成保留另由自动测试覆盖。
- 安装版启动、独立图库、旧项目与 54 张旧参考看板读取。

屏幕验收发现的对比评级双选、图片墙撤销快捷键、导航图漂移、AI 取消状态残留已经修正。另修复解码缓存清理后的图片方向恢复、异步旧响应写入隔离、细节重试目标保持以及关闭对比窗口释放图像。

自动验证：最终完整测试 **685 项通过、0 失败，469.47 秒**。日志 `build/qa/simpler-release-regression.log`；新增专项 18 项全部通过，日志 `build/qa/simpler-newtests-final.log`。其中包括 1000×700 窄窗口收纳、菜单实际排序切换、取消后的旧响应隔离、部分批量结果保留、撤销冲突保护与异步解码。

内存对比在相同 500 张图片全部解码完成后测量：看板源图像像素缓冲从 **280.27 MiB 降到 157.47 MiB，减少 43.8%**。这是像素缓冲计数，不是整个进程常驻内存；缓存间可能共享底层图像，不能简单相加。原始结果在 `build/qa/simpler-memory-before.json` 和 `build/qa/simpler-memory-after.json`。缓存预算是软目标，不包含模型、数据库及所有可见图像。

AI 取消会立即结束应用内的等待并阻止过期内容写入；已经发给模型服务的单次 HTTP 请求可能继续运行至返回。图片偏好反馈改善的是当前排序，不能保证每次语义判断都符合创作意图。

已安装 `/Applications/Eidory.app`，签名校验通过。安装后核对真实数据：23,497 张图片、8 个项目、85 个节点、223 个节点图片关联；项目与节点正文、参考用途和评级均与备份一致，仅打开项目的更新时间变化。SQLite `quick_check` 为 `ok`。

# UI 第一版与回退说明

日期：2026-09-11。运行库：PySide6 6.9.3。

## 本版调整

- 顶部固定项目切换、导航侧栏与信息侧栏开关；侧栏折叠后入口仍可见。
- 左侧分为图库与项目，当前项目节点与参考集放在项目页。
- 中央保留构思、找参考、已收集、看板四个入口，移除底部重复导航。
- 选图后在图片墙下方加入当前节点；支持撤销最近新增的引用，已有引用与其他节点不受影响。
- 右侧整理为详情、用途、标签；后台任务、索引与设置进入独立窗口。
- 保留／排除逻辑及每条条件的实时滑块沿用已接受版本；分组入口收进“更多”，匹配方式改为“全部满足／任一满足”。
- 中性深灰底色、统一主要与次要按钮、清晰下拉箭头；增加紧凑／舒展密度。
- 图片临时选中改为边框和勾选，保留金色“本项目已选”标记，不再在图片上覆盖蓝色蒙层。
- 看板常用操作集中，次要操作放入更多菜单；构思页面调整按钮排列。

本轮没有数据库结构迁移，没有改变筛选计算与 AI 内容生成逻辑。
“撤销加入”历史仅在当前运行会话内保留；可撤销的最近操作必须属于当前项目。

## Git 与软件回退

改版前已接受的功能保存为：

- 提交 `c16b9c121e34b4b8c279999df8de939fed671750`
- 标签 `checkpoint/ui-refresh-20260911`
- 本次改版分支 `codex/ui-workspace-refresh`

如需查看旧代码，工作区没有未提交修改时运行：

```sh
git switch --detach checkpoint/ui-refresh-20260911
```

返回本版代码：

```sh
git switch codex/ui-workspace-refresh
```

新版应用为项目目录下 `dist/Eidory.app`。先退出当前运行的 Eidory，再打开新版。
`/Applications/Eidory.app` 保持原版本，另有独立备份
`build/rollback/Eidory-before-ui-20260911.app`。
回退软件时退出新版，打开原应用或备份即可。回退代码不会自动替换应用包，也不会撤销用户后来保存的项目内容。

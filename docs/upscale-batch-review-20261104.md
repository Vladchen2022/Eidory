# AI 放大按批次审核 · 2026-11-04

版本 0.1.2，构建 20261104.2。

## 实际行为

1. 在图片墙多选图片，打开「AI 任务与结果」→「放大图库中所选图片」。每次提交形成一个独立批次。
2. 本机按队列依次放大。生成结果不会自动替换源图片，未审核的结果也不会阻止后续图片继续放大。
3. 本批次全部处理结束后显示提醒，统计待审核、失败和取消数量。点击「审核本批次」进入同一个对比窗口；也可以选择稍后审核。
4. 对比页显示本批次第几张、审核进度、原图文件夹、原图及输出尺寸。支持拖动中线对比、缩放、移动画面和结果 100%。
5. 每张可以「采用并替换原图」「采用并另存为副本」「放弃结果，保留原图」。仅在操作成功后进入下一待审张；取消另存或操作失败会留在当前图片。
6. 可以暂时跳过、前后查看或关闭窗口。稍后在任务中心选择对应批次并点击「审核所选批次」，从仍未决定的图片继续。

替换原图会保存恢复备份；放弃结果不删除源文件。在对应已审核图片上可撤销替换或放弃，恢复为待审核。另存副本不会覆盖原图，副本作为普通图库图片管理。

## 顺序与异常情况

- 审核顺序按本次提交时的选图顺序固定。调整执行队列顺序不会打乱审核顺序。
- 一次重试仍属于原批次、原图片位置；历史失败尝试保留在任务历史，但不会成为第二张待审图片。
- 批次里有失败或取消的任务时，成功结果仍可以审核。未确认状态、离线或暂停中的任务不算处理结束。
- 开始处理前发现源文件变化会停止该任务；审核时发现源文件被外部修改，会拒绝覆盖，并保留放大结果。
- 提交前被跳过的图片会在入队反馈中列出原因，不计入成功入队的批次。
- 旧版历史任务没有批次标识，保留原来的逐张打开方式；不推测或重组旧任务的批次归属。

## 实现与验证

批次标识和原始顺序保存于任务 JSON；整批入队使用同一数据库事务。审核以已有任务状态为准，重启后仍能恢复待审核项。完成提醒按批次及本轮任务标识去重，关闭提醒不会丢弃结果。

相关模块：`core/upscale_workflow.py`、`ui/upscale_tasks.py`、`ui/upscale_batch_review.py`、`ui/image_upscale.py`。

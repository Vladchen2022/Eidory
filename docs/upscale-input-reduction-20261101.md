# 大图 AI 输入缩小与撤销

修改前已备份代码、资源、原有未提交修改、正式应用与数据库，位置为 `build/rollback/upscale-input-reduction-20261101/`。开始和安装前的数据库快照均通过 quick_check，图片记录数为 28,397。

AI 页对长边超过 2048 的图片显示“缩小输入至 2048”。点击后按比例将 AI 输入限制到长边 2048，自动选择 2 倍，展示原图、输入及结果尺寸。再次点击“撤销缩小输入”，恢复之前的放大方式与指定长边。选择在本次应用运行中按图片保留，返回预览再进入仍可撤销。

按钮启用输入预处理；实际的 Lanczos 缩小在点击“开始放大”后由后台执行，只处理临时输入 PNG，不改动硬盘原图或图库记录。输出上限仍为 4096。大于 4096 的原图采用这种方式处理后，结果可能比原图分辨率低，尺寸行会明确提示。

任务保存 `input_info`、`input_reduced` 与完整的原始 `source_info`，重开、恢复运行或查看结果时使用任务实际提交的输入尺寸。旧任务缺少新字段时沿用原有路径，无需数据库迁移。任务运行、暂停核对或结果待处理期间固定输入参数；完成、取消或丢弃结果后可配置下一次处理。

提交前仍保存原图的完整字节备份。对比左侧使用完整分辨率、经过方向和色彩校正的 PNG，右侧才是 AI 结果，不用缩小后的输入充当“原图”。“替换原图”继续沿用原有事务、备份与崩溃恢复机制；“恢复原图”恢复完整原始文件及尺寸，不会只恢复到 2048。
